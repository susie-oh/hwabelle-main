## Checklist

- View page source on each core page and confirm title, meta description, canonical, OG, Twitter, and robots tags are route-specific.
- Confirm `https://hwabelle.shop/robots.txt` contains the sitemap reference.
- Confirm `https://hwabelle.shop/sitemap.xml` contains only canonical public URLs and no admin/account/order URLs.
- Confirm `https://hwabelle.shop/llms.txt` is publicly accessible and accurate.
- Run Google Rich Results Test on the home page, product page, and at least one article page.
- Run Schema Validator on home, product, and article pages.
- Run PageSpeed Insights mobile for the home page and product page.
- Submit the sitemap in Google Search Console.
- Use URL Inspection in Search Console for the home page, product page, shop page, designer page, and one article.
- Check mobile usability for home, product, and blog article pages.
- Validate social preview cards with a Facebook/Open Graph debugger and an X/Twitter card preview tool.
- Click-test internal links between home, shop, product, designer, about, resources, FAQ, contact, shipping, and returns.
- Check that no old `hwabelle.com` references remain in live source.
